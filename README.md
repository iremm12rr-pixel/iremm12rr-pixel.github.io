## 🌐 2. How to Deploy Live in 2 Minutes (100% Free)

### Option A: GitHub Pages (Recommended)
1. GitHub par ek naya public repository banao jiska naam rakho: `azixur.github.io` (ya koi bhi repository name).
2. Is folder ki saari files (`index.html`, `robots.txt`, `sitemap.xml`) us repository mein upload/push karo:
   ```bash
   cd /home/ajijur/azixur-rahman
   git init
   git add .
   git commit -m "feat: initial liquid glass portfolio for @azixur.rahman"
   git branch -M main
   git remote add origin https://github.com/azixur/azixur.github.io.git
   git push -u origin main
   ```
3. GitHub Settings -> **Pages** -> Source: `Deploy from a branch` -> Select `main` -> Click **Save**.
4. Tumhari site live ho jayegi: `https://azixur.github.io`!

### Option B: Vercel (1-Click)
1. Go to [vercel.com](https://vercel.com)
2. Drag & drop `/home/ajijur/azixur-rahman` folder
3. Instantly live with free SSL!
